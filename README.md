# Цветосфера

Локальная многопользовательская игра: один игрок описывает случайный цвет, остальные выбирают его на круге Oklab. За каждый ответ даётся до 5000 очков; ведущий получает средний балл угадывающих.

## Публикация через GitHub и Render Free

GitHub хранит код, а Render запускает сайт и игровой сервер вместе. GitHub Pages отдельно не подойдёт: ему негде выполнять Node.js и Socket.IO.

1. Создайте репозиторий GitHub и отправьте в него файлы проекта. Каталоги `node_modules`, `dist`, `data` и скачанный `cloudflared.exe` уже исключены из Git.
2. В панели Render выберите **New → Blueprint** и подключите этот репозиторий. Файл `render.yaml` создаст бесплатный Web Service с командой сборки, запуском и проверкой `/health`.
3. После успешного развёртывания откройте выданный адрес `https://…onrender.com`, создайте комнату и отправьте её ссылку игрокам. Локальный компьютер и Cloudflare Tunnel для этого не нужны.

Render Free может остановить сервис после 15 минут простоя и перезапустить его позже. При остановке, перезапуске или новом развёртывании текущая партия и сохранённая на сервере история исчезают. История в интерфейсе поэтому доступна только в пределах жизни текущего экземпляра. Для постоянной истории понадобится платный сервис с диском или внешняя база данных. Первый запрос после простоя может открываться около минуты. Автоматическое развёртывание отключено, чтобы обычный `git push` не прерывал партию; новые версии запускайте вручную в панели Render между играми.

## Локальный запуск на Windows

Нужен Node.js 24 или новее.

```powershell
npm install
npm run build
npm start
```

Сайт откроется по адресу **http://localhost:3000**. Сервер слушает только локальный компьютер. Во втором окне PowerShell запустите:

```powershell
npm run tunnel
```

При первом запуске скрипт скачает `cloudflared.exe` из [официального репозитория Cloudflare](https://github.com/cloudflare/cloudflared/releases/latest). В терминале появится временный адрес `https://…trycloudflare.com`. Откройте его, создайте комнату и отправьте игрокам ссылку приглашения. При новом запуске туннеля публичный адрес меняется. Держите оба окна PowerShell открытыми во время игры.

Для разработки используйте `npm run dev`; он запускает сайт и сервер на том же порту с горячей перезагрузкой.

## Правила

- Хозяин создаёт комнату; остальные входят по ссылке или восьмизначному коду, выбирая никнейм и встроенный аватар.
- Партия начинается при трёх подключённых игроках. Каждый участник стартового состава по одному разу становится ведущим в случайном порядке.
- Ведущий видит цвет и публикует текстовую подсказку до 140 символов. Цветовые коды блокируются; прямые названия цветов запрещены правилами компании.
- Угадывающие выбирают оттенок на круге и светлоту ползунком. После отправки ответа поменять его нельзя. Таймер — от 30 до 180 секунд; если все ответили раньше, результаты открываются сразу.
- Очки считаются по расстоянию между цветами в Oklab: `round(5000 × exp(-distance / scale))`. Строгость `1–5` задаёт `scale` от `0,24` до `0,08`. Неотправленный ответ даёт 0 очков. Ведущий получает среднее число очков всех угадывающих в этом раунде.
- Вошедший после старта может угадывать с ближайшего доступного раунда и участвует в общем рейтинге по сумме очков. Его ход ведущего появится в следующей партии.
- После результатов хозяин запускает следующий раунд. При равенстве очков победителей несколько.

Хозяин задаёт перед партией долю приглушённых цветов. При локальном запуске комнаты и результаты завершённых партий сохраняются в `data/rooms.json` и видны в истории комнаты после перезапуска сервера. Незавершённая партия после перезапуска сбрасывается в лобби.

Сервер не задаёт лимит игроков, но интерфейс и проверки рассчитаны прежде всего на компанию из 3–20 человек. [Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/) предназначен для тестирования и имеет ограничение на одновременно обрабатываемые запросы.
